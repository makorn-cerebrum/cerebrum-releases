# Cerebrum releases

Signed, sealed app packages for Cerebrum customers. Everything here is encrypted: you need a licence file from Cerebrum to install anything.

## Install
1. Download this repository (Code → Download ZIP) and unzip it.
2. Put the licence file Cerebrum sent you (`*.license.json`) in the same folder.
3. Double-click **Install Cerebrum.cmd**.

Apps check for signed updates every day. Your own data is never overwritten by an update.

## How it's protected
- Every package is encrypted (AES-256) and only opens with a key that Cerebrum issued for your licence.
- The index, packages and licences are signed by Cerebrum (RSA-3072). Your workstation refuses anything that isn't.
- Questions: contact Cerebrum.
